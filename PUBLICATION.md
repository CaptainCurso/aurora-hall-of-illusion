# Public publication

The project owner requested Git check-in and a publicly accessible GitHub location on 2026-11-05, superseding the prior LAN-only distribution instruction for this completed game. Publication is the reviewed v0.9.1 runtime and its maintainable source. Existing local LAN access and frozen historical builds are preserved.

Repository: https://github.com/CaptainCurso/aurora-hall-of-illusion

Play: https://captaincurso.github.io/aurora-hall-of-illusion/

The main branch contains an explicit file allowlist. Private campaign research, original source archives, role coordination, detailed local logs, unused images, raw production outputs, editable masters, personal paths, earlier prototypes and ZIPs remain local and ignored. All runtime media required to play the accepted release are included. Undocumented original campaign-art rights are disclosed in ASSET_PROVENANCE.md; no broad media reuse license is invented.

publish_pages.py verifies the selected release and prepares only its declared files plus notices and .nojekyll. Its optional --push creates/advances the dedicated gh-pages branch without rewriting main or force-pushing. GitHub Pages source is gh-pages / . No source secrets or private folders are used by the hosted runtime. No custom domain, router changes, external AI APIs or new paid services are required.

GitHub Pages publishes a static game. Browser storage belongs to each player and browser origin; LAN progress does not automatically transfer to the public URL. No play telemetry or server-side user data is collected by the game. GitHub supplies its own hosting behavior.

After automatic approval review required asset-specific consent, the owner explicitly answered: “Yes, publish the complete game and these assets publicly.” The question named Aurora’s existing portrait/projections, four campaign illustrations with undocumented original licenses, and generated derivatives, publicly viewable/downloadable through GitHub and GitHub Pages. That approval was obtained before the public push.
