# Maintained game source

This folder contains the editable source and referenced runtime assets for **Aurora-7: Hall of Illusion — Freedom™ After Dark**, including The Unscheduled Encore. It is development source; the selected playable release is declared by `../CURRENT_RELEASE.json`.

Use the project [README](../README.md) for current play links, controls, startup instructions, release identity and the known route. [Verification](../VERIFICATION.md), [asset provenance](../ASSET_PROVENANCE.md) and [publication notes](../PUBLICATION.md) describe accepted scope and distribution. The owner authorized LAN and public GitHub delivery; earlier local-only notes describe historical decisions.

Maintain the existing world, Encore and preference save keys. Preserve original media, prior immutable builds and accepted playback behavior. Freeze a new version with `../freeze_vnext.py`; promote it only after exact-build review. The launcher serves the selected immutable release on the LAN, not this mutable directory.

The previous v0.9.1 source guide was preserved verbatim in the local coordination history before replacement. Earlier release files and Git history remain unchanged.
